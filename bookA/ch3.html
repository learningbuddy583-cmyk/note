3.1數字系統與表示法 Number Systems and Representation

🎯 學習重點
  • 認識十進制、二進制與十六進制，並能互相轉換。
  • 說出數據單位（位元、字節、KB、MB、GB、TB）與位元速率單位。
  • 理解位元數與樣式數量（2^b）的關係，並能求表示 P 個樣式所需的位元。
  • 求無符號整數與有符號整數（二進制補碼）的表示範圍。
  • 定義二進制補碼與溢出誤差。

A 數據單位

數碼設備中，數據通常以下列單位量度。注意：數據單位基於二進制（1024），而位元速率單位基於十進制（1000）。

單位記號數值
位元bit / b數據的基本單位，可以是 0 或 1。
字節 / 位元組B1 B = 8 bits
千字節KB1 KB = 1024 B
百萬字節MB1 MB = 1024 KB
十億字節GB1 GB = 1024 MB
萬億字節TB1 TB = 1024 GB

位元速率（數據傳輸率）單位：bps、kbps、Mbps、Gbps —— 基於十進制（1 kbps = 1000 bps）。小寫「b」指位元（bits），大寫「B」指字節（bytes）。

✍️ 作答建議：儲存空間換算用 1024（二進制）；位元速率換算用 1000（十進制）。留意題目寫的是 KB（字節）還是 kb（位元）。

B 數字系統

我們日常使用十進制（基數 10）。數碼設備使用二進制（基數 2），因為它以位元（0 或 1）儲存數據。十六進制（基數 16）常用，因為一個十六進制數位正好代表 4 個位元。

實驗①

進制轉換器：輸入數值，即時看三種進制

自由試玩：先選輸入的進制，再輸入數值，另外兩個進制會即時更新，並連同展開式一起顯示，讓你看到數值是怎樣算出來的。

🧠 記憶口訣：二進制轉十進制＝「每位乘位值再加起來」；十進制轉二進制＝「不斷除以 2，餘數倒著讀」。

樣式數量

樣式（組合）的數量決定了可以表示多少數據。使用 b 個位元就有 2^b 個樣式；要表示 P 個樣式，需要 log₂P 個位元。

實驗②

位元與樣式：拖一拖，看 2^b 長得多快

自由試玩：拖動滑桿改變位元數，樣式數量、無符號範圍與有符號範圍都會即時更新。

4

D 表示無符號整數

無符號整數是沒有負號的整數，即正數和零。以 N 位元表示時，範圍涵蓋 0 至 2^N − 1。

E 表示有符號整數（二進制補碼）

有符號整數可以是正數、負數和零，約有一半樣式用來表示負整數。以 N 位元表示時，範圍涵蓋 −2^(N−1) 至 2^(N−1) − 1。

二進制補碼（二補碼）是多數電腦採用的方法。最左邊的位元具有「負」的位值：首位元為 0 表示非負數，為 1 表示負數。

實驗③

二補碼探索器：翻動位元，看數值怎樣變號

自由試玩：先選位元數，再點任一位元翻轉。十進制數值與正負號會即時更新——試試翻動最左邊那一位看會發生什麼。

4
✍️ 常見陷阱：整數 X 的二進制補碼是 −X 的二進制補碼數字。例如 3₁₀ 的二進制補碼是 101，而 101 是 −3₁₀ 的二進制補碼數字。留意「數字」二字。

F 溢出誤差

當計算結果超出位元數可以表示的範圍時，就會發生溢出誤差。

實驗④

溢出探索器：把兩個數相加，看結果裝不裝得下

自由試玩：選定位元數，輸入兩個整數，看看相加結果是否在範圍內。試試用 4 位元計算 3 + 5。

4
✍️ 判別重點：無符號整數——結果多出一個位元，或最左位元向「不存在的位元」借位，即溢出。有符號（二補碼）——兩個同號數相加而結果變號，即溢出；異號相加不會溢出。

3.2字符編碼 Character Encoding

🎯 學習重點
  • 說出 ASCII 的特點，以及它至今仍被使用的原因。
  • 比較大五碼、國標碼與統一碼，包括每個字符所需的字節數。
  • 解釋為何用錯編碼系統會出現亂碼。

除了數字，字符也有其表示方法，稱為字符編碼系統。不同語言可能使用不同的編碼系統。

常見字符編碼系統（點卡片查看）

A ASCII 探索

ASCII 通常使用 7 位元表示一個字符，因此可以表示 2^7 = 128 個字符。它有時會擴展為 8 位元（1 個字節），以表示更多字符、作奇偶檢驗位，或配合以字節為單位處理數據的系統。

實驗⑤

ASCII 探索器：輸入字符或編碼，即時互換

自由試玩：輸入單個字符可看到它的 ASCII 編碼；輸入十進制編碼（0–127）可看到對應字符。試試 A、a、0，留意它們的規律。

🧠 記憶口訣：ASCII 中數字按升序排列，大小寫字母按字母順序排列——所以「A」(65) 比「a」(97) 剛好小 32。
字符編碼系統比較表
語言字符編碼系統每個字符的大小
英文ASCII7 位元到 1 個字節
繁體中文大五碼2 個字節
簡體中文國標碼2 個字節
世界上大多數語言統一碼1 到 4 個字節（可變長度）

大五碼與國標碼不能互換——用國標碼去解讀大五碼檔案只會得到亂碼，而不會變成簡體中文。

✍️ 作答建議：以字符形式儲存的數字（如字串中的「3」）會佔用字符的空間（例如 16 位元），而不是整數的空間；字串中的空格也算一個字符。

3.3條碼編碼 Barcode Encoding

🎯 學習重點
  • 說出條碼的功能及特色。
  • 說出條碼與二維碼的組成元素。
  • 比較條碼與二維碼。

條碼在日常生活中廣泛使用，例如超市的包裝產品或零售商分發的優惠券。與手動輸入數字相比，掃描條碼可減少輸入錯誤和輸入所需時間。

條碼與二維碼（點卡片查看）

條碼與二維碼詳細比較
屬性條碼二維碼
掃描方向大多只能從兩個角度掃描，即 0° 或 180°。可從任何方向掃描；即使掃描器傾側令圖像扭曲，仍有機會成功讀取。
糾正錯誤的能力若單個條形或空格的寬度被更改，便無法正確掃描。糾錯能力較高，通常可恢復高達 30% 的數據。
可代表的數據種類部分可表示 ASCII 字符，另一些只可表示數字。可以表示統一碼字符。
可代表的數據量序列的最大長度約為 50 個字符。上限通常不少於 1000 個字符。
✍️ 作答建議：二維碼四個角中有三個定位標誌，所以能從任何方向掃描；即使中心被商標遮住，只要不超過約 30% 的數據，仍可解碼。

3.4模擬及數碼數據 Analogue and Digital Data

🎯 學習重點
  • 分辨模擬數據（連續）與數碼數據（離散）。
  • 解釋數碼化是「離散化」加「量化」兩個步驟。
  • 說明取樣頻率與數碼數據接近原本波形的關係。

以物理方式用連續值表示的數據（如聲波、沖印照片）稱為模擬數據；以 0 和 1 等離散符號表示的數據（如文字檔案、數碼照片、音頻檔案）就是數碼數據。

A 數碼化

數碼化是將模擬數據轉換為數碼數據，可分為兩部分：離散化（在固定時間間隔取樣）與量化（把取樣值四捨五入為一組特定的離散值）。

實驗⑥

取樣頻率：拖一拖，看數碼版本有多接近原本波形

自由試玩：拖動取樣率，比較左右兩幅波形。取樣率低→階梯粗糙、失真大；取樣率高→階梯細密，更接近原本的平滑波形。

12
模擬訊號（連續）
取樣後（數碼）

取樣頻率越高，表示在指定時間內取得越多樣本，數碼化時丟失的數據越少——但檔案也會變得更大。

模擬與數碼數據詳細比較
屬性模擬數據數碼數據
表示方式以實體表示，數值之間的變化是連續的。以離散符號表示，通常為 0 和 1。
數據儲存媒體的壽命通常較短且較不耐用。通常更長更耐用。
壓縮的可行性低。高，例如數碼電視訊號佔用較少的無線電頻譜。
防止傳輸複製時損壞的能力低。高，可套用奇偶檢測等有效性檢驗方法。
數據分析能力低，例如數據變動時需手動更新計算結果。高，例如電子試算表可自動更新數據甚至即時製作圖表。
⚠️ 常見陷阱：光符識別（OCR）本身不算數碼化，因為數碼圖像與電子書都已經是數碼數據。數碼化是「模擬 → 數碼」；把電子書或數碼圖像打印出來則是相反方向（數碼 → 模擬）。

3.5多媒體 Multimedia

🎯 學習重點
  • 說出多媒體的常見元素：文本、圖像、音頻、視頻與動畫。
  • 識別不同多媒體類型的常見檔案格式及其用途。
  • 分辨「未壓縮」、「無損壓縮」與「有損壓縮」三種儲存方式。
  • 比較儲存相同數據時各格式的檔案大小差別，並為情境選出合適格式。

多媒體（multimedia）指結合多於一種媒體元素的資訊，常見元素包括文本、圖像、音頻、視頻與動畫。這些元素經數碼化後，要以不同的檔案格式儲存——壓縮方式不同，檔案大小與質素也就不一樣。

文本 Text文字與符號；格式如 txt、docx、odt、pdf
圖像 Image靜態畫面；格式如 bmp、png、jpg
音頻 Audio聲音；格式如 wav、mp3
視頻 Video連續畫面＋聲音；格式如 avi、mp4
動畫 Animation連續播放的圖像序列，常內嵌於視頻或網頁

A 三種儲存方式（壓縮）

為甚麼要有這麼多格式？因為檔案大小與質素之間要取捨。同一份數據可以用「未壓縮」、「無損壓縮」或「有損壓縮」三種方式儲存。

🧠 記憶口訣：「未壓最脹、無損不失真、有損最輕身」。
· 未壓縮（bmp、wav）：原原本本記低，可 100% 還原，但檔案最大。
· 無損壓縮（png）：解壓後與原檔完全相同，檔案中等。
· 有損壓縮（jpg、mp3、mp4）：捨棄人眼／人耳不易察覺的細節，檔案最細，但無法還原。
選格式再記一句：「相片用 jpg、標誌用 png、原檔用 bmp／wav」。
實驗⑦

檔案大小探索器：壓縮到底省了多少？

自由試玩：切換「圖像／音頻」，拖動三個滑桿，所有檔案大小即時更新。同一份數據，用不同格式儲存，大小可以差好幾倍。

自由試玩：點一張格式卡選中它，再點下方的類型欄放下；電腦上也可直接拖放。放錯會彈回，放對變綠色。把 11 個全部分類就完成。

✍️ 作答建議：被問「選哪個格式」時，一定要寫「格式名 ＋ 原因（大小／質素／相容性）」：
· 要檔案細、放上網頁或是照片 → jpg（有損）
· 要透明背景、線條清晰、必須完全還原 → png（無損）
· 要保留全部原始數據作後製 → bmp／wav（未壓縮）
· 要跨平台版面一致、不易被改 → pdf
· 只要文字內容、不需格式 → txt
⚠️ 常見陷阱：「有損壓縮可以還原」是錯的；「檔案細就一定質素差」也不一定——png 就是既保質素又縮細檔案。

常考題型
  • 進制轉換：二進制／十六進制與十進制互換，有時要比較三個數值的大小。
  • 儲存空間計算：求 N 個檔案需要的 MB，或硬碟可儲存多少小時的音頻。
  • 樣式與位元：b 位元可表示多少個 ID；P 個參賽者需要多少位元。
  • 二補碼：求某數值的二補碼（數字），或把數個二補碼數字排序。
  • 溢出誤差：判斷哪一項計算會產生溢出誤差。
  • 編碼選擇：為包含多種語言的數據選擇字符編碼系統並說明理由。
  • 數碼化：判斷某動作是否涉及模擬與數碼數據之間的轉換。
  • 檔案格式選擇：為某情境選出合適的多媒體檔案格式，並以檔案大小、質素或相容性說明理由。
